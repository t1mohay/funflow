# Режь по рецепту! — дизайн-документ

> FunFlow Game Jam × ТПУ, вариант 3 «Разруби!» (референс Fruit Ninja).
> Сроки: старт 10.10, сдача 14.10. Движок: Unity 6.6, шаблон Universal 2D.
> Рабочее название, можно поменять.

## 1. Суть в одной фразе

Выбери блюдо и режь свайпом только те ингредиенты, которые в него входят: картошка в том яме испортит оценку.

## 2. Игровой цикл

1. **Меню.** Три карточки блюд: Салат ★, Пицца ★★, Том Ям ★★★. Один клик, и игра началась.
2. **Отсчёт 3-2-1.** На экране рецепт и подсказка «Свайпай мышью только по ингредиентам из рецепта!».
3. **Раунд 60 секунд.** Ингредиенты вылетают из-за левого и правого края поля и летят по параболе (вверх, потом вниз), игрок режет свайпом.
   - Нужный ингредиент: летит в кастрюлю, счётчик в рецепте растёт (`2/5`), зелёный отклик.
   - Лишний ингредиент: штраф, красная вспышка, тряска экрана, блюдо «портится».
   - Ингредиент, которого уже хватает (`5/5 ✓`): **перебор**, штраф −5 и подсказка «Уже хватит!».
   - Не разрезал нужный: просто упущенный шанс, без наказания.
4. **Конец попытки:**
   - **Победа.** Рецепт собран целиком за 60 секунд: плашка «Блюдо готово!», раунд заканчивается досрочно.
   - **Проигрыш.** Время вышло, а рецепт не собран: плашка «Время вышло!», грустный звук.
5. **Экран результата:**
   - Победа: «Том Ям готов! 85/100», звёзды, время сбора, разбор лишнего («Картошка ×2»), смешной вердикт шефа. Рекорд обновляется только здесь.
   - Проигрыш: «Том Ям не готов! Не успели!», сколько собрано, чего не хватило («Креветка ×2, Лайм ×1»), подсказка «Собери весь рецепт за минуту!».
   - На обоих экранах кнопки «Ещё раз» (R) и «Другое блюдо» (Esc).

Сессия: раунд 60 с плюс меню и результат дают около 1,5 минуты на блюдо, 2–3 блюда займут 3–5 минут. Это укладывается в требование брифа.

## 3. Экран раунда

```
┌──────────┬─────────────────────────────┬──────────┐
│  НУЖНО   │          ⏱ 0:42              │  БОНУСЫ  │
│ 🍅 2/5   │                             │ ⏳ Q  ×1  │
│ 🥒 5/5 ✓ │      (ингредиенты летят)     │ 🪙 W     │
│ 🥬 1/4   │                             │ 🛡 E  ×2  │
│ 🧅 0/3   │                             │          │
│ 🫑 3/3 ✓ │           🍲 кастрюля         │          │
│ Блюдо 62 │                             │          │
└──────────┴─────────────────────────────┴──────────┘
```

Слева «Нужно» со счётчиками, справа «Бонусы» — три слота способностей (раньше там был список «Не нужно»: всё, чего нет слева, — лишнее), в центре игровое поле. Текущая оценка видна всё время, так связь «действие → результат» читается сразу.

## 4. Формула оценки (0–100)

Оценка ставится только за готовое блюдо. Если время вышло раньше, это проигрыш без оценки.

```
оценка = 2 × (нарезано нужного, без перебора)
       − 3 × (лишние ингредиенты)
       − 3 × (перебор)
       + бонус за комбо
оценка = max(оценка, 0)   — потолка нет, больше 100 = «божественное блюдо»
```

В каждом рецепте ровно 50 нужных ингредиентов: весь рецепт без ошибок = ровно 100. Выше 100 можно уйти только за счёт комбо.

**Комбо (мульти-разрез):** 3+ нужных ингредиента одним движением (пауза между разрезами меньше 0,25 с). Бонус +5 за каждый ингредиент сверх второго: ×3 → +5, ×4 → +10. Лишний или перебор внутри серии её обрывает. Чтобы комбо случались, половина пачек летит «гроздью»: столбиком с одной стороны.


Звёзды: ≥ 90 ★★★, ≥ 70 ★★, ≥ 40 ★.
Если рецепт собран раньше времени, раунд заканчивается сразу, а на экране результата написано «Весь рецепт собран за N с!». Повод переиграть: собрать быстрее и без ошибок.

## 5. Блюда и ингредиенты

| Блюдо | Нужно (количество) | Лишнее |
|---|---|---|
| **Салат** ★ | Помидор 12, Огурец 12, Салат-лист 10, Лук 8, Перец 8 (= 50) | Шоколад, Пончик, Банан, Конфета, Рыба, Носок |
| **Пицца** ★★ | Сыр 10, Помидор 9, Грибы 9, Бекон 8, Оливки 7, Перец 7 (= 50) | Ананас, Клубника, Мороженое, Огурец, Печенье, Банан |
| **Том Ям** ★★★ | Креветка 9, Грибы 8, Чили 7, Лайм 7, Кокос 7, Лемонграсс 6, Галангал 6 (= 50) | Картошка, Морковь, Сыр, Хлеб, Молоко, Яблоко, Бекон |

Смысл подбора: в салате лишнее очевидно (шоколад, носок), в том яме есть ловушки, которые «почти подходят»: картошка, молоко вместо кокосового.
Количества подобраны под поток: за 60 секунд вылетает около 90 предметов, и хороший игрок собирает рецепт ближе к концу раунда, а не на 20-й секунде.
Все числа лежат в `Recipes.cs` и меняются за минуту.

## 6. Рост сложности

**Внутри раунда** (0 → 60 с):

| Параметр | Начало раунда | Конец раунда |
|---|---|---|
| Интервал спавна | 1,1 с | 0,45 с |
| Ингредиентов за раз | 1 | до 3–4 |
| Доля лишних | 20–25 % | 35–45 % (не больше одного лишнего в пачке) |
| Скорость полёта | ×1,0 | ×1,35 |

**Между блюдами:** чем больше звёзд у блюда, тем быстрее раунд, тем больше видов ингредиентов и коварнее лишние.

Спавнер чаще выбрасывает то, чего ещё не хватает, поэтому собрать рецепт реально. Ингредиенты, которых уже хватает, тоже иногда летят (вес 0,2 против 1 + недостающее у нужных). Резать их — перебор, штраф −5.

По симуляции (игрок попадает по 80 % нужных): ненужного летит около 20–26 % за раунд, рецепт из 50 ингредиентов собирается примерно за 42–51 секунду (из 60). До правки 10.10 было 58–72 % ненужного, и игра ощущалась слишком сложной.

## 7. Отклик (game feel)

- **День 1:** след свайпа, разрез на две половинки с разлётом, брызги-частицы, всплывающий текст `+1 Помидор` или `ЛИШНЕЕ −10`, тряска экрана на ошибке, процедурные звуки (свист, «плюх», «бзз»).
- **Дни 3–4:**
  - кастрюля внизу экрана, куда падают кусочки (суп меняет цвет от лишнего);
  - пульсация счётчиков;
  - комбо за 3 и больше нужных одним свайпом (+1 с ко времени);
  - редкие бонусы и способности (см. ниже);
  - нормальные звуки и музыка.

### Бонусы и способности

Раз в 10–14 секунд (первый — на 6–9-й секунде) вылетает бонусный объект в пульсирующем ореоле. Разрезал — заряд способности в панели «Бонусы» (до 2 зарядов на каждую), промах — без штрафа. Чаще выпадает то, чего меньше.

Отклик на разрез бонуса: стоп-кадр (время почти замирает на ~0,45 с и плавно разгоняется), искры, две ударные волны, тряска экрана, цветная вспышка, половинки бонуса разлетаются сильнее обычного, а соседние ингредиенты отталкивает взрывом.

| Способность | Клавиша | Длительность | Эффект |
|---|:-:|:-:|---|
| Замедление | Q | 5 с | игра ×0,45 (таймер тоже), музыка опускается ниже |
| Очки ×2 | W | 8 с | нужный ингредиент +4 вместо +2, комбо удваивается |
| Щит | E | 6 с | лишнее и перебор полупрозрачные, нож проходит сквозь них |

Пока способность действует, у слота идёт полоска времени, экран слегка подкрашен её цветом. Все числа — в `Abilities.cs` и `Spawner.cs`.

## 8. Управление

Зажать левую кнопку мыши и провести через ингредиент (палец тоже работает).
Режет только быстрое движение, медленное вождение мышью ничего не делает.
Q / W / E: способности (или клик по слоту). R: заново, Esc: пауза (в меню паузы — настройки звука и графики и выход в главное меню).

## 9. Техническое устройство (под вайбкодинг)

- **Почти всё создаётся кодом.** `GameBootstrap` при старте сцены сам собирает камеру, фон, спавнер, ввод и весь UI. Руками в редакторе ничего настраивать не надо, сцену не придётся мёржить между людьми.
- **Данные рецептов** лежат в одном C#-файле `Recipes.cs`.
- **Арт подменяется без кода.** Положи `Assets/Resources/Ingredients/<id>.png`, и вместо цветного кружка появится картинка. Пока картинок нет, игра рисует заглушки: кружок с подписью.
- **Ввод:** Input System (новый) с запасным вариантом на старый `Input`.
- В Unity 6.6 по умолчанию включён Fast Enter Play Mode, поэтому в коде нет статического состояния, которое переживает перезапуск Play.

| Файл | За что отвечает |
|---|---|
| `GameBootstrap.cs` | точка входа, сборка сцены |
| `GameManager.cs` | состояния: Меню → Отсчёт → Раунд → Результат |
| `Recipes.cs` | ингредиенты, блюда, параметры сложности |
| `RoundState.cs` | счёт, прогресс рецепта, формула оценки |
| `Spawner.cs` | вылет ингредиентов, кривая сложности |
| `Ingredient.cs` | полёт, разрез, половинки |
| `SwipeInput.cs` | свайп, след, проверка пересечений |
| `GameUI.cs` | меню, HUD, рецепт, результат |
| `Fx.cs`, `Sfx.cs`, `Art.cs` | частицы, тряска, всплывающий текст, звук, заглушки и загрузка спрайтов |
