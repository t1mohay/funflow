# Звук и музыка

Все звуки и музыка — оригинальные, синтезированы скриптами из `Tools/AudioGen` (Python + numpy/scipy, без сэмплов).
Общий стиль — ночной R&B / нео-соул: электропиано Rhodes, тёплые пэды, суб-бас, снэпы, реверберация.
Все музыкальные звуки настроены в **ля минор** и под темп **86 BPM**, поэтому эффекты попадают в гармонию с музыкой.
По этой же причине тональные звуки играются **без случайного сдвига высоты** (pitch = 1).

## Как это устроено

Все звуки запускаются через один компонент — `Assets/Scripts/Sfx.cs`. На каждое событие игры — своя функция.

1. При старте (`Sfx.Awake`) клипы загружаются из `Assets/Resources/Audio/<Папка>/<имя>` через `Resources.Load<AudioClip>`.
2. Если файла нет, функция играет старую процедурную заглушку, сгенерированную кодом. Поэтому игра работает и без ассетов,
   а новый звук подключается, если просто положить файл с нужным именем — код менять не надо.
3. Звуковые эффекты играются через пул из 16 `AudioSource` по кругу, поэтому несколько звуков могут звучать одновременно.
4. Если у звука несколько вариаций (`_01`, `_02`, `_03`), каждый раз выбирается случайная, чтобы частые звуки не надоедали.
5. Музыка играет на двух отдельных зацикленных `AudioSource`. При смене трека старый затухает, новый плавно нарастает (1,2 с),
   громкость музыки — 0.45.
6. Таймер конца раунда и отсчёт — важные сигналы: они играют через отдельный `AudioSource` с наивысшим приоритетом
   (их не обрывают другие звуки), а музыка на время сигнала быстро приглушается до 35 % и потом плавно возвращается.
7. Данные всех клипов подгружаются заранее (`LoadAudioData` + `preloadAudioData: 1` в `.meta`), чтобы звук не опаздывал при первом запуске.

## Подробнее о каждом звуке

### 1. Разрез еды — `PlayChop(id)`
Быстрый взмах лезвия со стальным призвуком, потом сочный «шлепок» с брызгами, сверху тихая нота Rhodes.
Тип звука выбирается по `Id` ингредиента (словарь `SliceKind` в `Sfx.cs`):

| Тип | Как звучит | Ингредиенты |
|---|---|---|
| `juicy` — сочное | мокрый шлепок, крупные брызги | помидор, лайм, ананас, клубника, оливки, молоко |
| `crunchy` — хрустящее | меньше сока, хруст | огурец, салат, лук, перец, чили, лемонграсс, морковь, яблоко, печенье |
| `soft` — мягкое | глухой шлепок | сыр, грибы, бекон, креветка, пончик, банан, рыба, носок, мороженое, хлеб |
| `hard` — твёрдое | глухой деревянный «тук» | кокос, галангал, шоколад, конфета, картошка |

Неизвестный `Id` (например, новый ингредиент) звучит как `soft`. Новый ингредиент — добавить строку в `SliceKind`.

### 2. Вылет еды — `PlayLaunch()`
Мягкий воздушный «фух» вверх и тихий суб-толчок на ноте ля. Без щелчков и свиста: вылет звучит часто, поэтому он тише остальных.

### 3. Счётчик — `PlayGood(fill)`
Нота Rhodes с октавой сверху. `fill` (0..1) — насколько собран этот ингредиент: чем больше собрано,
тем выше нота (10 ступеней по пентатонике ля минор: ля, до, ре, ми, соль, ля, до, ре, ми, соль).
Серия разрезов складывается в восходящее арпеджио.

### 4. Промах, взмах по пустоте, перебор
- `PlayMiss()` — короткий «дин-дун» колокольчиком вниз (в духе системного звука ошибки) с Rhodes.
  Звучит, только если упал **нужный** ингредиент, которого рецепту ещё не хватает, — лишние падают молча.
- `PlaySwoosh()` — тот же взмах лезвия, что в начале разреза, но без шлепка и тише.
- `PlayOverflow()` — пока использует звук промаха.

### 5. Ошибка — `PlayBad()`
Функция есть, своего файла пока нет — играет старый процедурный «бз-з». Чтобы заменить, положить `Error/error_01.wav` (и при желании `_02`, `_03`).

### 6. Выполнение задания и комбо
- `PlayComplete()` — арпеджио Rhodes вверх (ля, до, ми, соль, си) разрешается в светлый аккорд Cmaj9 с колокольчиком, снэпом, суб-басом и пэдом.
- `PlayCombo()` — короче: три ноты и аккорд без пэда.

### 7. Таймер конца раунда
- `PlayTimerTick(sec)` — на 5, 4, 3, 2, 1 секунде своя нота (ля → си → до → ре → ми), каждый тик чуть плотнее — растёт напряжение.
- `PlayTimeUp()` — финальный аккорд ля минор с колокольчиком и басом.

### 8–9. Музыка
- **Лобби** (`lobby_loop.ogg`) — оригинальная петля 16 тактов в стиле присланного референса (не копия):
  прогрессия Am9 → Fmaj9 → Dm9 → Esus → E7(b9), Rhodes, пэд, суб-бас, бочка, снэп на 2 и 4, хэты со свингом,
  тихий шум винила. Первые 8 тактов спокойные, во вторых 8 вступают хэты и мелодия Rhodes с дилеем.
  Хвост реверберации перенесён в начало — петля зацикливается без щелчка.
- **Раунд** — своего трека пока нет. `PlayMusic(MusicTrack.Round)` продолжает играть музыку лобби, не перезапуская её.
  Когда появится `Music/game_loop.ogg`, он подхватится сам с плавным переходом.

### 10. Отсчёт перед раундом
- `PlayCountdownTick()` — на «3», «2», «1» один и тот же тик (колокольчик + Rhodes на ноте ми, снэп, бочка) —
  в отличие от таймера конца раунда, высота не меняется.
- `PlayCountdownGo()` — на «Режь!» плотный аккорд Am9 с колокольчиком, бочкой, снэпом и суб-басом.
- Отсчёт в игре идёт шагами по 0,65 с, поэтому тики и старт запускаются кодом по отдельности.

## Изменения в коде

- `Assets/Scripts/Sfx.cs` — загрузка клипов из Resources, функция на каждый звук, `enum MusicTrack` и `PlayMusic`/`StopMusic`
  с плавной сменой треков. Процедурные заглушки сохранены.
- `Assets/Scripts/GameManager.cs`:
  - `PlayChop()` → `PlayChop(def.Id)` — звук по типу еды;
  - отсчёт: `PlayTick()`/`PlayGo()` → `PlayCountdownTick()`/`PlayCountdownGo()`;
  - последние 5 секунд: `PlayTick()` → `PlayTimerTick(second)`;
  - время вышло: `PlayLose()` → `PlayTimeUp()`;
  - комбо: `PlayGo()` → `PlayCombo()`;
  - `OnIngredientLost` — новый вызов `PlayMiss()` для упавшего нужного ингредиента;
  - музыка: `PlayMusic(MusicTrack.Lobby)` в меню, `PlayMusic(MusicTrack.Round)` в начале раунда.
- Старые имена `PlayTick()`, `PlayGo()`, `PlayLose()` оставлены, чтобы не ломать другой код.

## Как заменить или добавить звук

Положить файл с нужным именем в нужную папку `Assets/Resources/Audio/` — без изменений кода.
Форматы — любые, которые понимает Unity (WAV, OGG, MP3). Для музыки лучше OGG, для коротких эффектов — WAV.
Чтобы перегенерировать звуки, см. `Tools/AudioGen/README.md`.
