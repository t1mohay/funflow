# Ингредиенты для дизайнера

## Требования к картинкам

- PNG с **прозрачным фоном**, квадрат **512×512**.
- Объект занимает примерно 90 % кадра и стоит по центру.
- Все картинки в **одном стиле**.
- Должно читаться в маленьком размере: в панели рецепта иконка около 60 px.
- Половинки рисовать **не нужно**, игра режет картинку сама.
- Имя файла = английское имя из таблицы, например `tomato.png`.
- Куда класть: ингредиенты в `Assets/Resources/Ingredients/`, блюда в `Assets/Resources/Dishes/`. Игра подхватит их сама, код трогать не надо.
